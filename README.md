# 🎓 Student Management System 

A comprehensive, interactive, and modular **Student Management & Analytics System** built with **Python**, **Streamlit**, and **Plotly**. 

Version 2 introduces advanced OOP architectures, dynamic string IDs (e.g., `ST001`, `AI001`), smart case-insensitive search, detailed analytical dashboards, and automatic JSON data persistence.
